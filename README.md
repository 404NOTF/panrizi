# 盼日子

一个适合 iPhone 主屏幕使用的倒计日网页 App。可以自行添加、编辑、删除日子，选择分类、颜色、置顶和每年或每月重复；数据存在当前设备的浏览器里，可导出和合并导入 JSON 备份。安装过并打开一次后，App 的界面也可离线打开。

## 放到 GitHub Pages

1. 在 GitHub 新建一个仓库。将本文件夹内的全部文件上传到仓库**根目录**（不要只上传 ZIP）。
2. 进入仓库 **Settings → Pages**，将部署来源设为 **Deploy from a branch**，选择 `main` 分支的 `/ (root)`，保存。
3. 待 Pages 显示网站地址后，用 iPhone 的 Safari 打开该地址。点分享按钮，选 **添加到主屏幕**，并打开“作为网页 App 打开”。

如果你把文件放在仓库子目录，也可以将 Pages 的发布目录设为该目录（取决于 GitHub 提供的目录选项）；最省事的是直接放在仓库根目录。GitHub Pages 是公开网页：不要把私密的日子写进仓库源代码。你在 App 内新增的日子只存在该浏览器的本机存储里，别人访问网站看不到它们。

## 数据说明

- 不同浏览器、不同设备的数据不会自动同步。更换手机、清除网站数据或删除网页 App 前，请在“设置与备份”里导出备份，之后在新设备导入。
- 导入会按内部 ID 合并，不覆盖当前设备已有的同 ID 日子。
- 日期按手机当地日期计算，不受夏令时造成的小时差影响。
- 每月 29～31 日在较短月份按月末显示；每年 2 月 29 日在平年按 2 月 28 日显示。
- 这个版本没有系统通知或桌面实时数字小组件。

## 本机预览

在本文件夹执行 `python3 -m http.server 8000`，浏览器打开 `http://localhost:8000`。直接双击 HTML 文件时，离线缓存功能无法正常注册。
