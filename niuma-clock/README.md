# 牛马时钟

独立的 iPhone 主屏幕网页 App。不同星期可设多个上班、晚自习时段；日历上可做单日调整；寒暑假可单独填写日期和月薪。支持金额隐藏、工资日倒数、JSON 完整备份和 CSV 月度预计明细。

## 使用

Safari 打开网址 → 设置里填正常月薪、晚自习额外补贴、发薪日 → 排班页修改周班表 → 假期页填写实际校历 → 分享 → 添加到主屏幕。

预设：周一至周三 09:00–17:30；周二、周三晚自习暂设 19:00–21:00（请按实际开始时间修改）；周四、周五 07:15–15:45；周末不排班。日间时段默认包含午休，需要暂停计薪请拆成多个时段。工资默认为 0，避免将示例金额当作真实工资。

所有日期按 Asia/Shanghai。时段只在当天内，跨午夜需拆到两天。工资仅是估算展示；未自动读取学校校历、法定调休、工资单或银行到账。

## 估算规则

本月非假期工资池 = 正常月薪 × 非假期自然日数 ÷ 当月自然日数。分摊到非假期排班日，选择按天均分或按排班分钟分配，只在工作时段增长。非假期全月没有任何排班时，按非假期自然日全天分摊。

假期每天基本工资 = 假期月薪 ÷ 该日所在月份的自然日数，全天增长。不同假期不能重叠；单日调整优先于假期默认无排班，且不改变该日的假期基本工资。

晚自习每个时段视为一场，额外补贴随该场进度增长；包含在月薪里的请填 0。单日额外补贴随当日排班增长，无排班时全天增长。月薪制下单日休息不会自动扣薪；修改工资、周班表会重算历史估算，请导出备份或明细保存旧口径。每行金额保留两位小数，合计使用未四舍五入值。

## 隐私与备份

所有个人数据仅保存在当前设备、当前浏览器的 localStorage，使用独立键 `niuma.clock.v1`；网站源代码公开不包含实际输入的工资。站点与浏览器之间不自动同步，添加到主屏幕后的存储可能与浏览器不同，请导出并导入。清理浏览器前导出 JSON。导入替换当前内容前会再次确认。没有第三方依赖、分析代码或远程字体。

## GitHub Pages

将 本文件夹内的文件上传到 GitHub Pages 根目录，或现有 Pages 仓库的独立子目录。所有路径相对，子目录部署无需改配置。站点的 service worker 只管理自己的路径与 `niuma-clock-` 缓存。不要上传工资备份；它是私密数据。

## 验证

`node --test tests/engine.test.cjs`。界面支持 320px 以上屏幕。网页 App 无原生锁屏组件和后台通知；重新进入时直接用时间戳重算，无后台计时漂移。
